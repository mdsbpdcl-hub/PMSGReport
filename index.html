How it works

  1. Choose the SBPDCL and NBPDCL files (one is enough).
  2. Press Create report. The first time, the report engine is fetched; this takes about a minute.
  3. The Excel report is saved to your Downloads folder.
  4. With sending on, you type the upload password once, the report goes to the dashboard, and the dashboard opens.

Upload password

The password set for the dashboard upload. It is kept only while this page is open.
